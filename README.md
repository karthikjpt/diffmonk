## ⚡ What is DiffMonk?

DiffMonk is a lightweight, secure desktop wrapper for the DiffMonk comparison engine. It allows developers, writers, and data analysts to compare code, JSON, and text blocks instantly without relying on a web browser. 

Because DiffMonk processes everything locally on your machine, your sensitive code, proprietary algorithms, and private data never leave your device. 

## 🚀 Key Features

* **Instant Offline Access:** Loads in milliseconds and works entirely without an internet connection.
* **100% Local Processing:** Zero cloud uploads. Your data stays on your machine.
* **Smart Block Alignment:** Isolates logic chunks and auto-aligns matched blocks to pinpoint exact character changes.
* **4-Pane Comparison:** Compare up to four separate files or text blocks simultaneously with smart routing.
* **Deep Noise Reduction:** Ignore whitespace, hide matched rows, and collapse empty gaps to focus only on what changed.
* **Local History Sync:** Saves instant, timestamped snapshots of your workspace directly to your local database.

## 🔒 Security & Privacy

This repository contains the open-source Electron desktop wrapper for DiffMonk. We made this code public so you can verify exactly what is running on your machine.

The wrapper does two things:
1. Strips automated Chromium tracking flags to ensure maximum privacy.
2. Creates an isolated sandbox environment so the comparison engine can run locally without interfering with your system browser.

**Your data is yours.** We do not track keystrokes, we do not upload files to our servers, and we do not use your code to train AI models.
